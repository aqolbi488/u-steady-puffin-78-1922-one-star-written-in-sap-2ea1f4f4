A tiny deterministic program that writes a single one-line 1-star review from a houseplant about its human owner to `/output/entry.txt` — a monstera, moved six times in one month chasing "better light", now living on top of the fridge next to the pickles.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes the review to `/output/entry.txt` and always produces the same output.
